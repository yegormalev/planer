# Мой планер (PWA)

Личный планер, который открывается в браузере и ставится на айфон как приложение.

## Что внутри
- `index.html`, `styles.css`, `app.js`: само приложение, без сборки и зависимостей.
- `manifest.webmanifest`, `icons/`: чтобы планер ставился на экран «Домой».
- `sw.js`: работа без интернета и показ уведомлений.

## Как запустить у себя
```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Для установки на айфон нужен хостинг с HTTPS (подойдёт любой статический: GitHub Pages, Cloudflare Pages, Netlify).

## Установка на айфон
Открыть сайт в Safari, нажать «Поделиться», выбрать «На экран «Домой»».

## Допущения первой версии
- Данные хранятся только на устройстве (localStorage). Синхронизации между устройствами нет, есть резервная копия в файл в разделе «Ещё».
- Напоминания срабатывают, пока приложение открыто или недавно свёрнуто. Для уведомлений при закрытом приложении нужен сервер с Web Push (на iOS работает с 16.4 и только у установленного приложения). Пока вместо этого есть кнопка «В Календарь iPhone», которая отдаёт событие с напоминанием в системный календарь.
- «Поделиться» отправляет текст плана дня, задачи, заметки или отчёта по питанию через системное меню. Совместного редактирования нет.
- Меню питания заполнено примером без граммовок и калорий. Его можно править кнопкой «Меню» в разделе «Питание».
