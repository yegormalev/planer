# Мой планер (PWA)

Личный планер, который открывается в браузере и ставится на айфон как приложение.

## Что внутри
- `index.html`, `styles.css`, `app.js`: само приложение, без сборки и зависимостей.
- `menu-data.js`: рассчитанное меню на неделю. Собирается командой `node tools/build-menu.js` из таблицы продуктов.
- `learn-data.js`: план саморазвития на 30 дней со ссылками.
- `manifest.webmanifest`, `icons/`: чтобы планер ставился на экран «Домой».
- `sw.js`: работа без интернета и показ уведомлений.

## Как запустить у себя
```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Для установки на айфон нужен хостинг с HTTPS (подойдёт любой статический: GitHub Pages, Cloudflare Pages, Netlify).

## Установка на айфон
Открыть сайт в Safari, нажать «Поделиться», выбрать «На экран «Домой»».

## Допущения
- Данные хранятся только на устройстве (localStorage). Синхронизации между устройствами нет, есть резервная копия в файл в разделе «Ещё».
- Напоминания срабатывают, пока приложение открыто или недавно свёрнуто. Для уведомлений при закрытом приложении нужен сервер с Web Push. Пока есть кнопка «В Календарь iPhone».
- Повторяющиеся задачи создаются как отдельные записи на выбранный срок вперёд.
- План сушки: 82 кг, 186 см, 24 года, бокс 3 раза и силовой кроссфит 2 раза в неделю. Бокс поставлен на понедельник, среду и пятницу. Калорийность продуктов взята по усреднённым справочным значениям.
- Ссылки в плане развития найдены поиском. Открыть каждую страницу из среды сборки было нельзя, поэтому отдельные ссылки могли устареть.
